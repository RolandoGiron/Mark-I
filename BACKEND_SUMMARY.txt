1. FRAMEWORK ANALYSIS
================================================================================

Framework: FastAPI
Why FastAPI?
  - Modern async-capable framework
  - Auto-generated OpenAPI documentation (Swagger UI + ReDoc)
  - Built-in type validation via Pydantic
  - Excellent performance (ASGI based)
  - Perfect for REST APIs

Key FastAPI Components:
  - CORSMiddleware: Cross-origin request handling
  - Dependency injection: Built-in dependency management
  - HTTPBearer: JWT authentication support
  - StaticFiles: File serving for uploads

Documentation: http://localhost:8000/api/v1/docs (Swagger UI)

5. AUTHENTICATION & SECURITY
================================================================================

Authentication Type: JWT (JSON Web Tokens)
Token Expiry: 30 minutes (configurable)
Password Hashing: bcrypt (industry standard)
Algorithm: HS256

Security Features:
  - JWT tokens include: user_id, username, role
  - Dependency-based access control
  - Role-based authorization (RBAC)
  - Active user status checking
  - Admin-only endpoints protection
  - Expense validation permissions

User Roles:
  ADMIN       - Full system access
  GERENTE     - Project & expense management
  SUPERVISOR  - Expense validation & hour tracking
  TRABAJADOR  - Limited expense reporting & viewing

Authorization Dependencies:
  - get_current_user()          - Extract user from JWT
  - get_current_active_user()   - Verify user is active
  - require_admin()             - Admin-only access
  - require_gerente_or_admin()  - Multi-role check
  - can_validate_expenses()     - Permission-specific check

7. FILE STORAGE ARCHITECTURE
================================================================================

Storage Abstraction Pattern: Strategy Pattern
  - Abstract interface: StorageService
  - Two implementations: LocalFileStorage, MinIOStorage
  - Factory pattern: get_storage_service()

LOCAL STORAGE (Development):
  - Files stored in ./uploads directory
  - URLs: /uploads/{relative_path}
  - Configuration: STORAGE_TYPE=local

MINIO STORAGE (Production):
  - S3-compatible object storage
  - Pre-signed URLs (valid 7 days)
  - Configuration: STORAGE_TYPE=minio
  - Bucket management (auto-create)

Used For:
  - Invoice file uploads (JPG, PNG, PDF)
  - Maximum file size: 10MB (configurable)
  - Automatic filename generation with UUID

Configuration Approach: Pydantic Settings (BaseSettings)
Environment File: .env (example provided: .env.example)

Configuration Categories:

  APPLICATION:
    - APP_NAME, APP_VERSION, ENVIRONMENT
    - DEBUG mode (auto-creates tables)
    - API_V1_PREFIX (/api/v1)
    - HOST, PORT

  DATABASE:
    - DATABASE_URL (SQLite or PostgreSQL)
    - Automatic table creation in DEBUG mode

  SECURITY:
    - SECRET_KEY (must set in production)
    - ALGORITHM (HS256)
    - ACCESS_TOKEN_EXPIRE_MINUTES (30)

  CORS:
    - ALLOWED_ORIGINS (comma-separated)

  STORAGE:
    - STORAGE_TYPE (local or minio)
    - UPLOAD_DIR
    - MAX_FILE_SIZE

  FEATURE FLAGS:
    - TELEGRAM_BOT_TOKEN (Phase 2)
